# Smart Feedback Processor

Система автоматизированной обработки отзывов клиентов с анализом и подготовкой ответов на базе AI.

## Описание

**Smart Feedback Processor** — это интегрированное решение для гостинично-ресторанного и иных сервисных бизнесов, которым нужно:

- **Загружать отзывы** из CSV в единую базу данных
- **Анализировать отзывы** с помощью AI (OpenAI/GigaChat) для выявления проблем, оценки критериев качества, классификации задач
- **Генерировать ответы** на отзывы в едином корпоративном стиле
- **Выгружать результаты** для дальнейшего использования
- **Просматривать аналитику** по периодам, подразделениям, критериям качества

Система состоит из трёх компонентов:
1. **sfp_console.py** — консольное приложение для пакетной обработки отзывов
2. **sfp_web.py** — веб-приложение с интерфейсом для управления отзывами и аналитикой
3. **Аналитический дашборд** с визуализацией показателей и выгрузкой в CSV/PDF

## Функциональность

### 1. Загрузка отзывов
- Поддержка форматов: **CSV, JSON, TXT**
- Автоматическое определение разделителя (`;`, `,`, табуляция)
- Кодировка UTF-8 с BOM
- Маппинг полей: дата, ID клиента, имя, текст отзыва, ID подразделения, комментарии

### 2. Анализ отзывов
Консольное приложение с использованием AI модели анализирует:

**Структурированный анализ:**
- Позитивные и негативные элементы продукта/услуги
- Вопросы и предложения от клиентов
- Оценка по критериям качества (от 0 до 6 баллов)
- Выявление проблемных областей (оценки 1–3)
- Классификация задач для исполнителей

**Метрики тональности:**
- Эмоциональность (спокойная / эмоциональная)
- Форма общения (вежливая / грубая)
- Стиль изложения (деловой / неформальный)
- Общее настроение (негатив / взвешенно / позитив)

### 3. Подготовка ответов
AI генерирует профессиональные ответы, содержащие:
- Благодарность за отзыв
- Реакцию на позитивные и негативные оценки
- Ответы на вопросы и пожелания клиентов
- Подпись ответственного руководителя

### 4. Аналитический дашборд
Веб-интерфейс со сводной статистикой и динамикой:

**Плитки показателей:**
- Количество обработанных отзывов
- Средняя оценка отзыва
- Количество оценок критериев качества
- Доля проблемных оценок
- Количество задач в работу

**Графики (линейные):**
- Динамика количества отзывов по периодам
- Изменение средней оценки
- Соотношение позитивных и негативных оценок

**Таблицы:**
- Узкие места (критерии с наибольшим числом проблем)
- Задачи, поставленные по отзывам
- Эффективность подразделений

**Фильтры:**
- Пресеты периодов (весь период, последние 30/90 дней, последний год)
- Произвольный диапазон дат

### 5. Выгрузка результатов
Три варианта скачивания данных:

**CSV** (все отзывы с результатами обработки):
- 27 колонок (исходные поля + анализ + ответ)
- Разделитель `;`
- BOM для корректного открытия в Excel

**PDF** (аналитический отчёт):
- 3 страницы с графиками и таблицами
- Кириллица встроена (DejaVu Sans)
- Структурированные разделы со сводной статистикой

**Штатная выгрузка** (основная функция):
- CSV с исходными отзывами и результатами анализа
- Для дальнейшей обработки в BI-системах

## Требования к системе

### Обязательное
- **Python 3.10+**
- **SQLite 3** (встроена в Python)
- Интернет-соединение для вызовов API (OpenAI или GigaChat)

### Опциональное (для вёрстки PDF-отчётов)
- **Системные шрифты** с поддержкой кириллицы (DejaVu Sans, Liberation Sans)
- Для конвертации PDF в изображения: `pdftoppm`, `pdftotext` (утилиты Poppler)

## Установка

### 1. Клонирование репозитория
```bash
git clone <repo-url>
cd Module_FreeLance_FinProject
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

Файл `requirements.txt` содержит:
```
openai>=1.40.0
requests>=2.32.0
python-dotenv>=1.0.1
```

### 3. Конфигурация
Скопируйте `.env.example` в `.env` и заполните:
```bash
cp .env.example .env
```

Необходимые переменные:
- `OPENAI_API_KEY` или `PROXY_API_KEY` — API ключ для работы с моделями
- `OPENAI_BASE_URL` — адрес API (для ProxyAPI или самостоятельного хоста)
- Опционально: `MODEL_NAME`, `TEMPERATURE`, `OPENAI_MAX_TOKENS`

### 4. Подготовка справочников
Каталог `data/` содержит CSV-файлы с метаданными:
- `items_quality.csv` — критерии качества и привязка к подразделениям
- `items_services.csv` — типовые услуги и ремонты
- `items_responsibles.csv` — подразделения и руководители
- `items_mood.csv` — классификация настроения отзывов
- Шаблоны ответов (templates_*.csv)

Адаптируйте эти файлы под вашу бизнес-структуру.

## Использование

### Веб-приложение (рекомендуется)

```bash
python sfp_web.py
```

По умолчанию доступно на http://127.0.0.1:8000

Параметры запуска:
```bash
python sfp_web.py host=0.0.0.0 port=8080 settings_dir=data open_browser=no
```

Функции в интерфейсе:
1. **Загрузка** — выберите CSV-файл с отзывами
2. **Обработка** — запустите анализ через AI
3. **Аналитика** — смотрите дашборд с графиками и таблицами
4. **Выгрузка** — скачайте результаты в CSV или PDF

### Консольное приложение (пакетная обработка)

```bash
python sfp_console.py input_dir=./input output_dir=./output format=csv
```

Параметры:
- `input_dir` — каталог с отзывами (обязательно)
- `settings_dir` — каталог с справочниками (по умолчанию `data`)
- `output_dir` — куда сохранять результаты (опционально)
- `format` — формат вывода: `json`, `csv`, `txt` (по умолчанию формат входного файла)

## Система хранения данных

### SQLite базы

**feedbacks.db** (веб-приложение):
- Таблица `web_feedbacks` — отзывы и их статусы
- Колонки: ID, дата загрузки, содержимое, результат анализа, ответ, статус обработки, ошибки
- Индекс по статусу для быстрого поиска необработанных

### Справочники (CSV)

Каждый справочник содержит ID и название:
- **Критерии качества** (items_quality.csv): 14 критериев с привязкой к подразделениям
- **Услуги** (items_services.csv): 7 типовых услуг
- **Подразделения** (items_responsibles.csv): 6 отделов с ФИО руководителей
- **Настроение** (items_mood.csv): 3 класса (негатив, взвешенно, позитив)

Все справочники кодируются в промпты для AI при инициализации.

## Интеграция с внешними системами

### OpenAI API (рекомендуется)
- Модель: GPT-4, GPT-3.5-turbo или совместимая
- Температура: 0.7 (по умолчанию)
- Макс. токены: 1000 (по умолчанию)

Через ProxyAPI можно использовать и другие модели (Claude, Anthropic и т.д.).

### GigaChat (альтернатива)
- Поддержка через `ai_gigachat_processor/`
- Требует авторизацию по ключу Сбера

## Формат входящих данных

### CSV-файл с отзывами

```csv
feedback_date;client_id;client_name;feedback_text;responsible_id;actions_taken
01.06.2026;125;Иван Петров;"Отличный сервис, спасибо!";2;
03.06.2026;126;;Проблем не выявлено;3;"Проведена переподготовка персонала"
```

Поддерживаемые разделители: `;`, `,`, табуляция

Обязательное поле: `feedback_text` (текст отзыва)

### Поля отзыва
- `feedback_date` — дата отзыва (любой формат с датой)
- `client_id` — ID клиента (число)
- `client_name` — имя клиента (текст)
- `feedback_text` — текст отзыва (обязательно)
- `responsible_id` — ID ответственного подразделения (число)
- `actions_taken` — комментарии по отзыву (текст)

- **Обработка**: 1 отзыв ~ 5–15 секунд (зависит от API)
